# 共享工作室设备预约 · 交互原型说明

交付：`prototype.html`。原生 HTML、CSS、JavaScript 单文件，可本地打开，不请求外部资源，不保存跨会话数据。它是可修改的设计与行为样本，无后端、登录、真实库存或真实预约。设备名称、配件与预约数据均为虚构。

## 设计依据与范围

简报明确：面向偶尔使用的成员，设备四台（含一个长名称变体），一次预约一台，日期不早于今天，用途必填，成功后能找到预约并取消，取消有短暂撤销机会。

本次选择：以设备为入口，用“预约设备／我的预约”组织两类任务。四台设备直接展开，搜索承担名称和型号查找，不增加分类导航。桌面把设备列表与预约表单并列，保留选择参照；窄屏沿同一阅读顺序上下重排，选中设备后定位到表单。尚无成员研究证据，“直接选择比多页向导更适合本次短任务”是可用性假设，并非已验证结论。

采用简洁的器材室工具语气。浅暖底色减轻大面积空白，深绿只用于主要动作、选择和确认；错误用红色及完整文字，选中用边框、勾号和状态文字共同表达。设备小图形仅辅助识别，不承担操作信息。

## 用户路径

1. 浏览四台设备，也可输入名称、型号或类别。选择后，表单显示完整设备名称。
2. 日期默认浏览器本地今天，可更改。选择一个 2 小时时段，填写用途。切换设备保留日期和用途、清除原时段；切换日期也清除时段。
3. 提交先验证输入。字段错误保留全部内容，并聚焦第一处需要修正的字段。
4. 等待期间展示“正在提交预约”，暂时禁用表单、设备选择、导航及演示结果设置，避免重复提交和改变正在提交的数据。
5. 模拟失败时保留设备、日期、时段与用途，显示可执行的“再次提交预约”。成功后自动进入“我的预约”，显示确认信息和预约卡片。
6. 取消直接生效，记录仍保留并改为“已取消”。对应卡片提供 20 秒撤销窗口；超时后可“重新预约”，带回原数据再次确认。

导航往返保留尚未提交的选择、用途与搜索条件。提交成功后清空表单草稿。搜索无结果不会清除已选设备或正在填写的表单。

## 关键组件与状态

| 组件 | 状态与行为 |
| --- | --- |
| 设备卡片 | 展示类别、完整名称、虚构配件说明及选择按钮；选中有深绿边框、勾号与“已选择”。按钮提供完整设备名称的可访问名称。 |
| 日期字段 | 原生日期输入，显示标签与提示；最早日期按浏览器本地日期计算，提交时再次检查。允许预约今天的任一提供时段，未额外引入“开始时间不得早于现在”的业务规则。 |
| 时段组 | 原生单选按钮，外观为 2×2 选项；键盘沿用原生单选行为。已确认预约占用同设备同日期同时段，显示“已预约”并不可选。 |
| 用途字段 | 原生多行文本，必填且不能仅含空白。输入作为文本显示，不当作 HTML 解析。无额外字符上限；长内容自然换行。 |
| 提交反馈 | 正常、等待、字段错误、系统失败、成功分开；失败旁有重试动作。等待没有虚构百分比。提交成功才新增预约。 |
| 我的预约 | 初始空状态提供“去预约设备”；非空状态列出时间、用途、编号与确认状态。导航数量表示已确认预约数，取消记录仍在列表中。 |
| 取消与撤销 | 取消后聚焦对应卡片标题，倒计时开始；鼠标停留或键盘焦点进入撤销区域时暂停，离开继续，页面后台时暂停；另有“延长 20 秒”。撤销恢复确认状态。若窗口内时段已被新预约占用，明确提示无法恢复并保留重新预约入口。 |
| 无搜索结果 | 独立文案说明没有匹配项，提供“清除搜索”；与“我的预约”初始空状态采用不同原因与动作。 |
| 原型演示区 | 页面底部独立折叠区，注明不属于成员界面。可选“失败一次，再试成功”、1.6 秒或 5 秒等待；失败开关仅影响下一次有效提交。刷新或重置按钮清除全部数据。 |

## 视觉与实现约束

- 页面最大宽度 1200px；桌面左右内边距 32px，主内容两栏约 1.16∶0.9、间距 32px。950px 以下收紧间距；740px 以下为单栏，表单取消吸顶。360px 以下时段改为单列。该断点以四张设备卡与可输入表单的空间需求作初始设置，待统一浏览器检查验证。
- 设备名称、用途和表单中的已选名称都不截断，不设固定文本高度；长英文允许必要换行。所有弹性列使用可收缩宽度。没有固定在屏幕底部的提交栏，以免窄屏与软键盘遮挡输入。
- 字体使用系统界面字体，后备包含 PingFang SC、Microsoft YaHei 与 sans-serif；未捆绑字体。主标题桌面 36px、窄屏 29px，区域标题 21px，设备标题 16–17px，正文输入 15–16px，说明 12–14px。没有验证最终系统字体来源或合成字重。
- 核心颜色：正文 `#22332e`、次级文本 `#61706a`、页面底色 `#f7f8f4`、主要动作 `#245f49`、错误 `#9e3327`、焦点 `#a45a12`。这些是本原型的局部设计变量。
- 主要操作至少 46px 高；窄屏设备选择按钮 44px。可见焦点为 3px 外轮廓；原生标签、fieldset/legend、错误描述关联、动态状态消息与跳过导航链接已编码。减少动态效果偏好下停止加载图形旋转。
- 图形为本文件内自绘 SVG，不需要图片、字体、网络服务或第三方素材。不得把它们作为设备实物照片或准确外观依据。

## 验证记录与后续验收

本次已执行：读取指定候选 Skill 及其更新后的界面方法；复核简报与实际原型代码的状态覆盖；抽取内联脚本通过 JavaScript 语法检查；静态检查 HTML 的唯一固定 ID、没有外部脚本／样式／媒体引用，并检查最终交付文件存在。语法与静态检查不证明交互或视觉通过。

本次未执行：打开浏览器、指针与键盘真实操作、截图评判、宽窄屏实测、200% 文字放大、实际字体渲染、屏幕阅读器、颜色对比测量、软键盘和不同浏览器检查。没有实际用户测试，也不声称符合某项完整无障碍标准。浏览器验收由另一执行者统一进行。

建议统一验收的代表路径：

1. 桌面初始进入“我的预约”查看空状态，再返回选择设备并提交成功。
2. 设置“失败一次”及 5 秒等待，填入数据提交；等待期间重复点击无效，失败后四项内容仍在，重试只新增一条预约。
3. 空用途、仅空白用途、空日期、早于今天和未选时段均不能提交；修正后能成功。
4. 成功预约占用的时段不可再次选择；取消释放时段，撤销恢复占用；移开焦点与鼠标后倒计时到期，延长和重新预约可用。
5. 搜索“咖啡机”查看无结果，再清除搜索。选择完整长名称设备，在 390px 与 320px 窗口完成预约、查看、取消及撤销。
6. 使用键盘完成主要流程并检查焦点，放大文字，观察长名称、长用途以及表单输入时的可见区域。

最终实现若接入服务端，需要另行定义真实库存冲突、请求结果不确定、刷新恢复与跨用户并发；这些属于本原型以外的工作。
