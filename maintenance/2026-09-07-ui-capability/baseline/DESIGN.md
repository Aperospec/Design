# 间作共享工作室 · 设备预约原型

交付文件：`prototype.html`。在现代浏览器中直接打开即可使用，无依赖、外部字体、图片请求或后端服务。所有设备、时段占用与预约数据均为虚构；刷新重置。

## 用户路径

1. 进入“设备预约”，浏览四台设备，或按名称、类别和描述搜索。初始明确选中 Studio Camera A7 IV，也可点击其他设备更换。
2. 选择日期、一个两小时时段，并填写用途。日期默认明天，避免初次打开时今天的时段已经结束。可以改为今天及以后的日期；过去日期与已经开始的时段不能提交。
3. 提交期间显示等待状态，并暂时锁定会改变预约的控件。成功后在原表单区域显示设备、日期、时段与用途的确认回执，提供“查看我的预约”和“继续预约”。失败保持所选设备、日期、时段与原用途，主按钮变为“再试一次”。
4. “我的预约”按日期和时段排列。本次会话尚无预约时展示空列表与“去选设备”入口。
5. 每条预约可打开取消确认框。保留预约或按 Esc 返回；确认取消后立即移出列表，并提供 10 秒撤销入口。撤销恢复原预约。多个取消分别保留各自的撤销窗口；若期间该时段被重新预约，撤销会说明无法恢复。

## 结构与视觉依据

这次设计需要让偶尔使用的成员辨认设备、完成单台设备预约，并在提交后找回结果。因此主要关系是“选择对象—填写条件—确认结果”。采用设备列表与表单并排的桌面结构，减少前后页面跳转；手机按同一顺序纵向排列，选定设备后移到表单，并在已选设备处保留“更换设备”入口。

设备列表使用文字主导的行式布局，完整名称是主要识别信息，小幅自绘 SVG 轮廓辅助区分相机、录音机、灯具与工作站。SVG 是示意图，不模拟真实产品照片。长中英混合设备名完整换行，不截断或缩小字号。表单回执、预约列表与取消确认框同样保留完整名称。

页面用浅暖灰背景区分工作区，以白色划定内容容器。深绿色只承担主操作、已选设备和已确认状态；错误使用红色，并始终附文字。选中设备同时有边框、底色、勾号和程序化状态，不只依赖颜色。演示控件使用不同底色、虚线边界和明确标题，与成员流程分开。

没有引用外部视觉参考。按实际内容选择了稳定的行式列表；四个名字长短差异明显，行式结构允许文字自然增长，也保持同一设备与其说明的紧密归属。没有为设备强制制作等高图片卡片。

## 实现规格

- 桌面内容最大宽度 1160 px；主要两栏比例为 1.2 : 0.85，间隔 32 px。表单在桌面滚动时保持在视窗内。
- 760 px 及以下改为单栏，左右留白 18 px；触控主按钮和时段约 48 px 高。移动端设备名称保持 15 px，输入日期、搜索使用 16 px，减少输入时的意外放大。
- 字体使用系统字体栈：`-apple-system, BlinkMacSystemFont, PingFang SC, Microsoft YaHei, sans-serif`。中文及英文实际字形取决于系统；未捆绑字体。桌面主标题 36 px，正文 15 px，设备名称 16 px，表单文字 13–14 px，辅助信息 11–12 px。数字使用表格数字样式请求；没有宣称所有平台都已实际生效。
- 内容容器圆角 16–20 px，输入框 8 px。基本间距使用 8、12、16、20、24、28、32 px，按文字量适配。
- 主色 `#24543e`，正文 `#24332c`，次要信息 `#627067`，页面底色 `#f5f5f0`，错误色 `#9f352f`。
- 使用原生按钮、表单、日期输入、单选时段和 `dialog`。标签与错误信息具有关联；可见键盘焦点、跳到主要内容入口、状态播报，以及减少动态效果偏好支持均已编写。
- 一次提交仅创建一台设备与一个时段的预约。用途拒绝空白字符串；显示预约用途时做 HTML 转义。已预约时段不可重复提交。
- 可用时段为 09:00—11:00、11:00—13:00、14:00—16:00、16:00—18:00。相机的 11:00 时段、工作站的 14:00 时段是固定模拟占用。当天已经开始的时段显示“已结束”。
- 撤销通知 10 秒后消失。如果撤销按钮正处于焦点，消失时将焦点送回预约页面的有效入口。此处只模拟预约流程，没有实现跨成员竞争、通知或跨会话存储。

## 演示状态

页面底部展开“原型演示控件 · 仅供检查”：

| 需要检查的状态 | 操作 |
| --- | --- |
| 初始空列表 | 刷新或“重置整个原型”，打开“我的预约” |
| 搜索无结果 | 搜索“无人机”，再使用“查看全部设备”恢复 |
| 等待 | 将等待设为 6 秒，填写有效内容并提交 |
| 失败与重试 | 选择“失败一次，再试成功”，提交后再次点击“再试一次” |
| 成功 | 正常提交，在回执中打开“我的预约” |
| 取消与撤销 | 取消一条预约并确认，在 10 秒内点击“撤销” |
| 长名称 | 选择“多机位移动直播与混合现实采集工作站 Blackmagic ATEM Mini Extreme ISO 便携整合套装”，完成预约并查看列表与取消框 |
| 输入错误 | 不选时段、用途留空，或选择过去日期后尝试提交 |

## 验证覆盖

已编写所有要求的页面与交互分支。JavaScript 的 `node --check` 语法检查通过；静态 HTML 检查确认固定 ID 无重复、资源标签无外部 URL，并确认日期输入、用途长度限制、原生对话框、状态播报与窄屏样式入口存在。这些是文件检查结果，不代表交互已在浏览器执行。

按本次分工，未自行打开浏览器，也未截图或执行实际点击。因此暂未验证真实排版、窄屏溢出、系统字体替换、原生日期选择器、对话框焦点与键盘顺序、屏幕阅读器播报或定时交互的实际效果。响应布局与无障碍行为属于已实现但尚待运行核验的内容，不能据此宣称通过视觉检查或用户测试。后续统一验证应优先覆盖 390 px 和 1440 px、长设备名、失败保留输入、成功入列和取消撤销全路径。
