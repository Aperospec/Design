# Design UI 能力补齐：方法与样本验收

2026-09-07。结论：design-craft 1.2.0-alpha 的本次明确 UI 方法缺口已补齐，并以真实交互原型与只读表格验证可执行性。发布与安装的最终提交和指纹见 Design 项目根 UI_CAPABILITY_DELIVERY.md。本轮结束，不重启自动建设。

## 补充了什么

| 已确认缺口 | 新增操作方法 |
|---|---|
| 页面视觉以外的信息架构 | 从用户任务、前置条件、对象关系和数量范围形成导航与路径；已有局部结构有效则直接修改 |
| 行为与反馈 | 动作、状态、反馈、下一步与恢复；输入错误、系统失败、空状态、取消/撤销与异步处理分别判断 |
| 组件与系统 | 以用途、语义、内容、状态/变体、输入与焦点、组合及约束建立复用依据，不预建通用大组件库 |
| 适配与无障碍 | 以信息和操作可达性判断重排、局部二维例外、键盘与焦点、名称/角色/状态及动态反馈 |
| 验证与实现衔接 | 实际任务路径、恢复与反例检查；区分模型、技术及用户证据；交付画面之外的行为与约束 |

新增三个按需参考文件，主入口及UI元数据更新，共12个安装文件。此前七份视觉参考逐字节保留，未删除方法、承接语义或变更ECD/Producer职责。专业依据见research/SOURCES.md；随技能分发的依据放在interface-method-basis.md，阅读局限保留在研究记录。

研究与独立审核使用MIT任务分析教学、Nielsen原作者启发式及定性测试、GOV.UK组件贡献标准、W3C规范/解释和Apple布局指导的已读部分。不是完整课程、全书阅读或专业认证。独立审核提出“只有结构不明确才做线框/流程”的条件化修订，已采纳；另补充数量确实影响组织时的范围判断。

## 真实试用及其解释

同一BRIEF.md分别交给两个独立执行者，仅提供各自Skill、原型要求和输出位置。旧版产物在baseline，新版原始产物在forward，父任务修订并验收的最终副本在accepted；不得用最终修订副本冒充未经干预的独立首稿。原型是虚构设备预约，与任何现有产品无关，不加入安装包。

旧版也完成并通过了主要路径。新版并没有在这一道显式要求较完整的题目上证明普遍优于旧版。采用新版的依据是用户授权扩大界面能力、经专业依据与独立审核确认的方法覆盖，以及独立执行产生了可工作的界面、状态和交付依据；不是“文档更多所以更专业”，也不虚构性能提升百分比。此次并非多次随机、盲评或真实用户对照研究。

实际检查了：空列表及无结果恢复、无效日期与必填、等待和防重复、失败保留输入及重试、成功后找到预约、取消与撤销；新版另实际用键盘从表单经过日期/时段/用途到提交，核对焦点样式。桌面1280×900、375×812及320×812在内置浏览器执行，实际查看截图与DOM几何。

父任务与独立代码审核发现两处前向原型边界缺陷：全时段不可用时的错误提示/焦点、撤销遇到重新预约冲突时焦点丢失。冲突在原型中实际复现；最终副本两者均通过实际界面操作复测，并回归正常预约、失败重试与撤销。额外修正了旧全局提示和时段名称，详见BROWSER_CHECKS.md。它们属已有方法执行缺陷，未新增案例专属规则。

只读表格反例实际交付并检查：4产品×6月，7列标题、4行标题的语义正确；320宽整页无额外横溢出，表内278宽承载704宽二维表，通过Tab和方向键滚动。375宽原生截图确认说明重排、长名称和焦点轮廓。它没有被强加编辑/提交或强制单列。海报局部修改只作指令路由审查；未虚报制作新海报。

## 保留边界与停止条件

- 项目属性硬隔离：虚构工作室、设备、文案、日期、预约规则、配色字体、断点和计时值全部只在维护案例中。平台规范由项目选定后查适用条款，通用Skill没有统一Web/macOS/iOS皮肤或参数。
- 本次验证支持“有可调用的通用UI方法，并完成有限原型实践”；不等于成熟覆盖全部UI场景，不证明真实用户易用性、完整WCAG合规、读屏体验、原生端行为、动态文字放大或跨浏览器兼容性。
- 以恢复路径为目的的额外检查止于已发现缺陷及相邻回归。没有安排下一轮、打开定时建设或创建新项目任务。
- 原维护工作树原有AGENTS.md改动未覆盖、未纳入本次提交；提交仅包含本次Skill、README与维护证据。
- 受管浏览器启动失败后按规则保留未确认关闭的ledger，未强制操作；实际检查由内置浏览器完成。工具限制、结构校验依赖和截图异常的处理完整保留在BROWSER_CHECKS.md。

复验入口：先读TEST_PLAN.md与BROWSER_CHECKS.md，再用现代浏览器打开accepted/prototype.html或counterexample/table.html。脚本只做本地虚构交互，不发真实预约请求。源码版本可用Git回退；安装和分发一致性另核验。
