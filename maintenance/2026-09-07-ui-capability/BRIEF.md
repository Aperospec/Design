# 界面设计试用：设备预约

为一个虚构的共享工作室设计设备预约界面，面向偶尔使用的成员。用中文、少量必要英文设备型号。交付一个无外部依赖、能在现代浏览器本地打开的 HTML 交互原型，以及供实现者使用的简要设计依据。无需后端、登录、真实预约或外部服务。项目风格由你选择，以清楚、克制、可用为准。

成员应能查看可预约设备，选择设备和日期/时段，填写预约用途，提交预约，在“我的预约”中找到它，并取消预约。设备包括 Studio Camera A7 IV、便携录音机 Zoom H6 和可折叠摄影灯；放入一个很长的中英混合设备名作为内容变体。一次预约仅一台设备，日期不早于今天，用途必填。取消已确认预约后提供短暂撤销机会。

原型须能演示提交等待、提交失败后再试（保留已填写内容）、成功、列表初始为空以及搜索无结果。将用于模拟结果的演示控件和真正给成员的界面区分开。提供可操作的手机窄屏与桌面布局。所有数据为虚构，刷新可重置；不要求跨会话保存。

用原生 HTML/CSS/JavaScript 即可。输出 prototype.html 和 DESIGN.md。DESIGN.md 说明用户路径、关键组件/状态及交付依据，诚实写明验证覆盖。只编写当前原型，不改变 Skill 或安装，不声称实际用户测试。必要检查按可用工具执行；若使用终端浏览器，必须先读 /Users/newcrown/.codex/skills/playwright/SKILL.md 且只用其隔离包装器与独立会话，禁止系统 Chrome/CDP。原型后续由另一执行者统一验证。
