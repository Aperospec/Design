# Design Craft：知识与方法升级

2026-09-06。候选版本 `1.1.0-alpha`；改前基线 `809a36ca3cc46a3f4f74ad7071dcc4b9c0c42070`。本轮补强从传播任务选择可见关系、用实际文字与图形验证选择的能力。原拆分修复的方法完整保留，新增内容按问题进入既有参考，没有恢复部门、固定审批或统一风格。

本轮有真实渲染与修订、有独立执行和看图复核；没有人类受众、真实设备、印刷或动态播放试验。故障样张是人为设置的合成案例，**没有旧新版 Skill 在同一未见任务上的因果对照**，不能说这些故障是旧版实际生成的。未因增加规则数量宣布能力成熟。

## 能力覆盖与本轮重点

| 能力目标与可观察表现 | 本轮依据与产物 | 当前证据缺口 |
|---|---|---|
| 从传播问题建立关系：读者知道该辨认、归属或比较什么 | MIT 视觉传达课程、信息变量课程；01 分组与 02 编码 | 传播前提是否来自真实受众需求，本轮未测 |
| 组织构图：层级、留白和阅读路径支持内容 | 01 同文同字号，仅移动活动标签；06 两种图文结构 | 未证明复杂长文、空间环境或印刷布局迁移 |
| 字体与混排：真实字形、断行和比较列可读 | CLReq、OpenType、字体制作者；03/04/05 原生字样、字形运行、局部修复 | 光学字号轴、合成粗斜、竖排、流式重排未实测 |
| 色彩与图文层级：颜色与图形承担明确关系 | 02 同色量值对照；06 图文并置/空间参与；策展与课堂作品实际观察 | 本轮没有系统色彩感知、色觉差异或媒介色彩试验，原有方法保留 |
| 序列和变体：对象可跨状态对应，变化有意义 | 序列论文；独立执行两状态、总览、同模板单图 | 只验证静态状态与并置，不宣称运动节奏、语言/尺寸变体已通过 |
| 评议修订：看见缺陷、修原因，再看新产物 | 三个代理各自研究/复核/前向执行；原证据错误和视觉遮挡均有实际关闭记录 | 模型的重心/阅读判断不等于人类观看表现；未取得专家实评 |

能力地图、阅读日志和测试输入仅在维护目录。本项目字体、画布、主题、颜色、数值与评审安排没有成为 Skill 默认值。

## 来源如何改变操作

完整阅读范围、日期、定位、访问失败与反例见 [形式与传播研究](research/form-communication.md)、[字体研究](research/typography.md)、[知觉、序列与评议研究](research/perception-sequence-critique.md)。课程用于找能力结构，论文用于机制与验证边界，规范用于适用条件，作品用于形式观察；书目与销售介绍不算读完书。

| 改动位置 | 原方法不足及新增操作 | 保留条件与反例 |
|---|---|---|
| Skill 入口、composition | 原有层级要求未充分区分归属、排序、量值；现在先确认关系任务，对照分组信号及可见编码 | 精确查值可用表，地理/形态任务可保留面积与位置，开放感受不强造唯一答案 |
| visual-concept | 已有不同方向比较，补裁切、重组、图底与图文单独/合看的实际试验 | 06 不支持“整合一定优于并置”；冗余与直接说明仍有效 |
| typography | 原字体证明未清楚区分请求名称、实际字体和字形；补特性核验、局部断行与数字两维度 | 指定字体不重做选秀；正文不强制等宽；无光学字号能力不伪造支持 |
| sequence | 已有连续与节奏，补必要中间关系、稳定参照和等价内容比较 | 静态模板与单图保留；艺术省略和动作本身有意义的动态设计仍开放 |
| critique | 原实际看图要求未明确什么证据能证明什么；补具体读图任务和验证层次 | 不要求普通修订强制招募读者；不以模型分数或像素正确替代专业效果 |

底层仅保留可执行方法与简短 [依据及适用边界](../../skills/design-craft/references/method-basis.md)。研究引用没有给本项目素材额外授权，来源作品未复制到分发素材。

## 实际作品、变化与判断

| 产物 | 画面中的表现和实际结果 | 判断强度 |
|---|---|---|
| [01 标签归属](artifacts/01-grouping.png) | 左稿中第一活动靠近下一时段，阅读顺序与距离竞争；右稿活动贴近各自时段，组间停顿清楚。大标题和整体模板保留，未靠新增框或换风格取得变化 | 作者与独立模型看图均可指出位置及后果；支持这组布局改善，不给出读者错误率 |
| [02 数量编码](artifacts/02-quantity.png) | 大小差异由夸大恢复为忠实映射；共享基线让端点直接可比，正确面积版仍保留整体面积感 | 实读 PNG：故障面积比约 4.012、修订约 1.991、条长约 2.031，对应数据比 2；阈值/抗锯齿产生近似。精确几何不是感知结果 |
| [03 字体对照](artifacts/03-type.png) | 同文同字号可见黑体与宋体的笔画、内白和正文肌理差别；没有普遍胜者。Georgia 样句触发宋体及箭头的其他后备 | [字体运行](artifacts/font-runs.json)记录显示样句、实际字体/文件/版本。样张支持做角色选择，未证明某字体更好 |
| [04 数字比较](artifacts/04-numerals.png) | 同一等宽数字在右对齐时，小数点横向跳动；以小数点为锚后上下列更稳定，整数/小数可对应 | 运行度量跨度从 25.576 px 到 0；同一数值、字体、特性不变。支持该列结构改善，不证明速度提升 |
| [05 局部断行](artifacts/05-linebreak.png) | 原稿行首逗号和短尾打断句子；局部断行后标题名及说明连续，避免挤整段字 | 字符串逐字一致；固定稿实际修复。未测试自动禁则引擎或复杂压缩 |
| [06 图文草图](artifacts/06-word-image.png) | 左稿的端点与线直接显示连接，右稿让文字进入分隔块面，形式参与更明显，但跨接和先后读序更含混 | 独立模型修后评议认为左稿更适合本次直接说明，右稿应保留为未胜出的探索；不能推广为分区永远优于融合，也不能归因于单一变量 |

## 失败、无差异与边界

- 01“等距”标签不符合实际位置，已改成“间距关系含混”；02 初版度量常数只代表公式，后增加实际 PNG 测量；03 原先 JSON 的代表句与显示句不完全对应，现记录完整显示句。均属证据记录/执行问题，没有据此增加永久禁令。
- 04 初版左对齐证明的是整数位差异；改为右对齐后才覆盖不同小数位。03 两个字体都能容纳内容，不编造胜者。
- 本批说明/比较样张选用 PingFang SC 延续标题、标签与正文角色，文字肌理与图形线条关系较一致；宋体留作同尺度候选。这个局部选择不声称宋体不适合说明，也不进入底层默认。
- 06 的评议副本曾在移除评价文字时误去左稿正文，独立评议发现信息不等价。已保留错误副本及评语、修正副本重评；不能把这次错误算成原设计缺字或方法失效。
- 旧版已经有真实文案、取舍证明、主体保护、光学校正、全序列/代表精修区别、准确授权和制作往返。本轮没有删掉这些方法；变化不能全部归功于新增文字。
- 未运行论文模型或复现实验，也没有阅读所列书目的整本内容。视觉结果是合成简报下的本机作品，不能冒充客户实战、专家授课完成度或整门学科掌握。

## 复现、保存与分发范围

`scripts/render-studies.swift` 由 macOS AppKit/CoreText 生成六张板；`scripts/verify-artifacts.py` 用 Pillow 读取实际像素及 JSON。`forward/render.swift` 是独立执行者的来源。脚本、确切文案、颜色与参数只在维护目录，不安装。

改前 Skill 归档为 [baseline/design-craft-809a36c.tar](baseline/design-craft-809a36c.tar)，首轮样张与记录在 `artifacts/iteration-1/`，独立评议的错误副本在 `validation/review-iteration-1/`。官方结构校验使用临时 PyYAML 依赖完成；本地引用与修改差异检查另有验证记录。结构正确不代替本报告的作品判断。

受管终端浏览器缺少指定 Chromium，启动失败且正常清理结果不可确认，保留本任务 ledger，没有强制清理或修改设置。原作网页后用内置浏览器成功查看；本机样张仍以 AppKit 渲染，不宣称浏览器兼容性。Git 命令没有终端 GitHub 凭据，镜像分发使用既有连接器，不读取凭据。

版本保存和分发按现有本地控制仓库 → iCloud bare 真源 → GitHub 同提交镜像执行，仅安装 `skills/design-craft`。最终提交、安装指纹、真源恢复和镜像状态以项目根目录 `KNOWLEDGE_UPGRADE_DELIVERY.md` 为准，避免在提交内部自引用未确定的哈希。

下一轮值得取得的证据：真实读者在含义等价图文中的阅读差异；一个有原始草图及专家修订评语的实际设计过程；流式中英混排与光学字号、竖排的真实渲染。它们是待验证范围，不是已安装能力的效果承诺。
