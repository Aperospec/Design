# 视觉概念与参考转译

视觉概念决定什么关系、空间、观看位置、比喻或证据组织方式能使内容变得可感知。它不同于“复古”“高级”等风格标签，也不等于选好颜色和字体。

## 找到需要看见的关系

从任务判断：首先应注意什么，随后应理解什么；对象之间发生了什么变化；哪些内容必须保持字面含义和可识别身份，哪些可以用比喻；画面可能造成什么误读。记录已经确定的判断和仍有选择空间的部分，不要求另写完整简报。

涉及证据、产品能力、复原或模拟时，先辨认画面允许表达的事实强度。逼真的视觉效果不提供新的事实依据；重建图不能自动成为现场记录，概念图不能成为功能已实现的证明。

## 读参考，然后转译

先确认参考的实际用途：直接使用的内容、质量基准、构图或字体研究、历史语境、反面例子等。用户要求使用一份参考，不自动代表可以复制其中每一项表达。

将以下判断分开，以免把喜好当事实：

1. **描述**：实际看见的主体、空间、尺度、光、材质、文字、图像、序列和观看位置。
2. **形式分析**：质量分布、层级、视线方向、景深、明暗、色彩、密度、节奏及图文关系如何组织。
3. **解释**：这些形式可能产生什么感知、情绪、含义或行为。解释需由观察支持。
4. **转译**：当前任务能借鉴什么关系；允许直接使用什么；应排除哪些来源特有的角色、标识、构图或表达。保留会影响理解的出处、日期、版本和使用条件。

不必为轻微参考使用提交四份报告，但不能把四种判断压成“参考它的高级感”。质量参考也不能被当成复制其身份、品牌和画面的许可。真实权利条件不清时核对所需用途，不凭视觉相似或标注出处推断许可。

## 比较真正不同的方向

当核心关系未定且探索有价值时，用低成本草图、结构图、粗拼贴或明确的空间设想比较方向。让方案在有后果的维度上不同，例如：

- 观众在场景之内还是旁观；靠近细节还是看整体；
- 用文字主导、图像主导还是证据主导；
- 通过并置、尺度、空间、过程、对比或隐喻揭示关系；
- 信息一次显现还是随时间或序列展开；
- 张力来自冲突、秩序、缺口、节奏或其他具体机制。

换字体或颜色可以是局部设计试验，但不能冒充不同视觉概念。方案数取决于仍未解决的问题；无需每次重做已有方向，也不以无限探索推迟交付。

探索性图像应保持探索状态。选择进入实际设计前，检查它能否容纳内容、证据与目标变体，不仅看孤立图像是否吸引人。

## 按结果取舍

比较方案是否表达任务中的关系，是否让需要阅读的内容获得位置，是否符合观看条件，是否会误导证据或模仿来源特有表达，以及是否有可执行路径。说明选中方案解决什么问题、放弃方案损失或多出了什么；可行性应参与判断，但不预先把创意限缩为最方便的工具效果。

对原创方向可用两个诊断问题：去掉参考后，这个方案是否仍能用任务目的解释？换成无关内容后，它是否仍几乎不变？后一个问题揭示可能缺少内容关系，不是禁止模板；已有品牌系统、系列设计和用户要求复用的模板，应检查其适配效果，而非强制发明新形式。

把选定的视觉关系、观看位置、文字／图像／证据权重及仍开放的变量传递给构图和图像工作。不要把后续版式、字体、制作参数全部提前锁死。
