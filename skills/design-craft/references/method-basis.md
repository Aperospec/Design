# 方法依据与适用范围

以下是可追溯的专业依据，不是完整教材、固定流程或项目模板。教学练习、知觉研究、技术规范与设计者评议提供不同强度的证据；本技能将其转成有条件的操作，不把来源中的作品、参数或个案结论移为默认。需要专门规范或当前工具兼容性时再核对适用版本。

## 图文与形式试验

- Bo-Won Keum，MIT *Visual Communication Fundamentals*，课程文件正文标 FA2024（文件名含 25fa），课程说明与课程结构：[教学大纲](https://architecture.mit.edu/sites/default/files/course-documents/25fa-4.053-syll-keum.pdf)。支持从抽象、重组、裁切、尺度与并置做实际形式试验，不能用课程书目证明已掌握书中方法；课堂媒介与交付安排不随之采用。
- Elizabeth Resnick，MassArt，2021，[Three Expressive Modes of Visual Language](https://teachingresource.aiga.org/project/three-expressive-modes-of-visual-language-the-practical-the-poetic-the-persuasive/)，Project Brief / Reflections；[Word and Image: Rebus Poster](https://teachingresource.aiga.org/project/word-and-image-rebus-poster-in-class-exercise-2/)，Reflections。支持比较图文结合后的含义，并把概念落实到构图；教学中的字谜与多义性不适合替代所有直接信息。
- Ellen Lupton，2015，[Experimenting with Type](https://www.cooperhewitt.org/2015/05/18/wolfgang-weingart-experimental-type/)。策展文字展示字形作为图底与结构的读法；这是保留实验性表达的依据之一，不是可读性普遍优越的实验证明，也不授予复制作品的许可。

## 分组与信息编码

- Rosenholtz 等，CHI 2009，*An Intuitive Model of Perceptual Grouping for HCI Design*，[作者论文](https://web.mit.edu/rruth/www/Papers/RosenholtzEtAlCHI2009PO.pdf)，Results / Discussion；Palmer，2002，*Perceptual Grouping: It's Later Than You Think*，[作者论文](https://palmerlab.berkeley.edu/pdf/Palmer.pdf)，pp.102–105。支持把实际分组与语义归属对照；知觉受多个线索与整幅情境影响，不能用一个间距比或简单模糊算法替代读者判断。
- MIT 6.813/6.831，2017，[Graphic Design](https://web.mit.edu/6.813/www/sp17/classes/13-graphic-design/)，Contrast / Characteristics of Visual Variables。区分类别、顺序、量值与可见变量；课中界面例子及变量数量估计不作为普遍限额。
- Heer 与 Bostock，CHI 2010，*Crowdsourcing Graphical Perception*，[作者论文](https://hci.stanford.edu/publications/2010/crowd-perception/heer-chi2010.pdf)，Experiments 1A/1B/3。为精确比较时采用共享尺度位置作对照提供实验依据；孤立编码、特定任务的结果不能推广成所有图形的总排名。编码忠实性还须由实际数据与几何核对。

## 字体与混排

- W3C，[中文排版需求](https://www.w3.org/TR/2026/DNOTE-clreq-20260901/)，2026-09-01 **Group Note Draft，进行中**，§6.1–6.4。用于按地区、禁则与可调空白处理中文/混排；未获 W3C 认可为正式标准，不能代替当前任务的出版体例，也不代表排版软件已经实现。
- OpenType，[光学字号 opsz](https://learn.microsoft.com/en-us/typography/opentype/spec/dvaraxistag_opsz)，2024-05-29；[数字特性 pnum / tnum](https://learn.microsoft.com/en-us/typography/opentype/spec/features_pt)，2024-05-31。提供字形设计与字宽功能定义，不保证某个字体含有这些能力。
- Type Project，2024，[Tabular Figures and Proportional Figures](https://staffblog.typeproject.com/en/3381) 与 [Lining Numbers and Old Style Numbers](https://staffblog.typeproject.com/en/3402)。用于分开判断数字字宽与字形高度；所示字体默认行为不能推广到别的字体。
- W3C，[CSS Fonts 4](https://www.w3.org/TR/2026/WD-css-fonts-4-20260831/)，2026-08-31 **Working Draft**，Controlling synthetic faces / Font Matching / Optical sizing。提供匹配、合成与实际字形可能不同的机制；只迁移核验思路，不给其他排版工具强加 CSS 操作。

## 序列与评议

- Tversky、Morrison、Bétrancourt，2002，*Animation: can it facilitate?*，[作者论文](https://www.tc.columbia.edu/faculty/bt2158/faculty-profile/files/_Morrison_Betrancourt_AnimationCanitfacilitate.pdf)，§2–4。说明性序列需检验必要步骤、可观察性和比较条件；该文对教学研究的综述不能推出动画普遍无效，或取代对实际运动的检查。
- Munzner，2009，*A Nested Model for Visualization Design and Validation*，[作者论文](https://www.cs.ubc.ca/labs/imager/tr/2009/NestedModel/NestedModel.pdf)，§2.3–2.5、§3.2–3.7。用于区分待证主张与验证手段，以及追查较早层次的问题；不照搬成固定设计阶段，更不把实现检查当成用户效果。

上述来源支持诊断与方案形成；本技能的综合操作仍须在当前作品中检验。不能将这些链接当成已读完全部原著、已做受众实验或已获素材再使用许可的证明。
