# Design Craft

Visual and UI design, interaction, typography and critique.

This is an independent, project-neutral skill. Its entry point is [SKILL.md](skills/design-craft/SKILL.md). Install the complete `skills/design-craft` directory, including its references. It can be used directly; no ECD studio, producer or other department is a prerequisite.

Project objectives, audiences, styles, formats, research conclusions, operational targets and permissions belong to the project and are supplied per task. They must not become defaults in this skill or its supporting files.

This first independent edition is an alpha. Structural validation and limited forward tasks establish initial evidence, not comprehensive mastery of every discipline named in its scope.

The 1.1.0-alpha knowledge update adds conditional methods for perceptual grouping, information encoding, word–image studies, actual font verification, explanatory sequences, and task-specific critique. [Research and rendered comparisons](maintenance/2026-09-06-knowledge-upgrade/REPORT.md) document the evidence, counterexamples, and untested scope. Maintenance materials are repository evidence; install only `skills/design-craft`.

A focused [word–image follow-up](maintenance/2026-09-06-word-image/REPORT.md) preserves actual earlier compositions, revises their visible relationship, and records independent viewing before the task purpose was disclosed. It adds process research and visual evidence while retaining the existing runtime methods and version; it does not claim a new-versus-old Skill performance gain.

The [copy and canvas variant study](maintenance/2026-09-06-variants/REPORT.md) separates longer wording from a narrower canvas, preserves its preliminary crop probes, and checks actual text grouping, connection landmarks, and whole-sentence reading. It records useful revisions and their costs while keeping the runtime Skill unchanged.

The 1.2.0-alpha update adds task-based interface structure, interaction and recovery states, component behavior, adaptive accessibility checks, and design handoff. [Bounded UI validation](maintenance/2026-09-07-ui-capability/REPORT.md) preserves the same-brief independent trials, a read-only table counterexample, observed defects and fixes, and untested scope. The seven earlier visual references remain unchanged. These results are limited prototype evidence, not a full usability or accessibility certification.
